01 — Attiva la telemetria

Attiva una volta la registrazione della telemetria.

LMU Telemetry legge i file prodotti direttamente da Le Mans Ultimate. Attiva la registrazione prima di aprire l'applicazione di telemetria.

  1. Apri Le Mans Ultimate.
  2. Apri il gioco Settings.
  3. Scorri fino alla sezione Extra.
  4. Attiva l'opzione di registrazione della telemetria.
  5. Lascia attiva l'opzione per le sessioni future.
Completato quandoLa registrazione della telemetria è attiva nelle impostazioni Extra.
Cosa succede: Le Mans Ultimate crea file telemetrici per le sessioni registrate. LMU Telemetry legge direttamente questi file.
02 — Scarica e avvia LMU Telemetry

Scarica LMU Telemetry da GitHub.

Apri la pagina Releases del progetto e scegli un pacchetto dell'applicazione Windows con versione, non gli archivi automatici del codice sorgente di GitHub.

  1. Apri la pagina ufficiale LMU Telemetry Releases .
  2. Scegli LMUTelemetry-Setup-VERSION.exe per installare, oppure lo Portable ZIP per eseguire l'app senza installazione.
  3. Facoltativamente scarica SHA256SUMS-VERSION.txt per verificare il file.
  4. Non scegliere Source code ZIP o tar.gz di GitHub se vuoi l'applicazione Windows.

Windows ha mostrato un avviso di sicurezza?
Verifica che il file provenga dalla pagina ufficiale LMU Telemetry Releases. Confronta il nome con il pacchetto della release e, quando disponibile, verificalo con i checksum SHA-256 forniti. La configurazione attuale non dichiara un'identità di firma del codice, quindi Windows può mostrare avvisi di reputazione. Non disattivare globalmente l'antivirus e non proseguire con file provenienti da fonti non verificate.
03 — Controlla la cartella della telemetria

Controlla dove Le Mans Ultimate salva la telemetria.

Avvia LMU Telemetry, apri Career Mode → User Profilee verifica la cartella rilevata automaticamente. La lettera dell'unità o il prefisso della libreria Steam sono le parti che più facilmente possono differire.

  1. Avvia LMU Telemetry.
  2. Apri Career Mode, quindi seleziona User Profile.
  3. Individua il campo Telemetry folder .
  4. Verifica che l'unità e la cartella Telemetry finale siano corrette.
  5. Se necessario, scegli Browse e seleziona manualmente la cartella corretta.
Completato quandoIl percorso selezionato termina con Le Mans Ultimate\UserData\Telemetry.
G:\SteamLibrary\steamapps\common\Le Mans Ultimate\UserData\Telemetry

Solo un esempio: `G:` non è obbligatorio. Il gioco può trovarsi in `C:`, `D:`, `E:`, in un'altra unità o in un'altra libreria Steam.

Lascia selezionata la cartella rilevata e prosegui con Save & Sync.

Cartella mancante o errata

Seleziona Browse, individua la directory LMU `UserData\Telemetry` e scegli quella cartella Telemetry.

04 — Importa le sessioni esistenti

Importa le sessioni che hai già disputato.

Quando la cartella è corretta, premi Save & Sync. LMU Telemetry analizza i file nativi delle sessioni e crea lo storico memorizzato nella cache usato da Career Mode e Plan Mode.

  1. Premi Save & Sync in User Profile.
  2. Mantieni aperta l'applicazione durante la prima scansione.
  3. Segui la fase di elaborazione, il messaggio e la percentuale mostrati dalla schermata di caricamento.
  4. Attendi lo stato di completamento oppure leggi l'errore mostrato se l'operazione non riesce.
  5. Al termine, controlla Career Overview e i migliori giri convalidati.
Completato quandoLa schermata di caricamento si chiude senza errori e Career Overview mostra le sessioni trovate nella cartella selezionata.
La prima sincronizzazione può richiedere tempo. Uno storico ampio può richiedere diversi minuti e l'interfaccia potrebbe rispondere lentamente. Non chiudere subito l'applicazione. Le sincronizzazioni successive esaminano i file nuovi o modificati senza rielaborare le sessioni invariate.

Risoluzione dei problemi

Mantieni breve il flusso principale. Apri solo il problema che corrisponde a ciò che stai riscontrando.

La cartella della telemetria non è stata rilevata
  1. Verifica che la registrazione sia attiva in Le Mans Ultimate.
  2. Verifica che il gioco abbia creato almeno un file telemetrico.
  3. Controlla in quale libreria Steam è installato il gioco.
  4. In Career Mode → User Profile, vai a `Le Mans Ultimate\UserData\Telemetry`.
  5. Verifica la lettera dell'unità e la cartella Telemetry finale.
La cartella è vuota

Le sessioni completate prima di attivare la registrazione potrebbero non aver prodotto i file necessari. Completa una nuova sessione registrata, poi verifica se Le Mans Ultimate sta scrivendo nella cartella `UserData\Telemetry` di un'altra libreria Steam.

Save & Sync sembra bloccato

Uno storico iniziale ampio può richiedere diversi minuti. Segui fase, dettagli e percentuale visibili e lascia terminare l'operazione. Se non cambia nulla per un periodo insolitamente lungo, riavvia l'applicazione e controlla i log. Per un problema riproducibile, apri una segnalazione su GitHub indicando versione dell'applicazione, versione di Windows, numero o dimensione approssimativa dei file, log pertinenti, screenshot della cartella selezionata e passaggi per riprodurre il problema. Controlla che log e file telemetrici non contengano informazioni private prima di condividerli pubblicamente.

Windows blocca l'eseguibile

Torna alla pagina ufficiale Releases e verifica nome del file, voce della release e checksum SHA-256 quando forniti. Il pacchetto attuale non dichiara un'identità di firma, quindi SmartScreen può mostrare avvisi di reputazione. Non disattivare globalmente l'antivirus e non proseguire con file da fonti non ufficiali.

Le sessioni precedenti non compaiono
  • Le sessioni potrebbero essere precedenti all'attivazione della telemetria.
  • I file potrebbero trovarsi in un'altra cartella della libreria Steam.
  • I file non validi o non supportati possono essere ignorati.
  • I file potrebbero non essere ancora stati elaborati con Save & Sync.
Ho installato Le Mans Ultimate su un'altra unità

Di norma cambiano solo l'unità e il prefisso della libreria Steam. Questi sono esempi, non percorsi garantiti:

  • C:\Program Files (x86)\Steam\steamapps\common\Le Mans Ultimate\UserData\Telemetry
  • D:\SteamLibrary\steamapps\common\Le Mans Ultimate\UserData\Telemetry
  • G:\SteamLibrary\steamapps\common\Le Mans Ultimate\UserData\Telemetry
