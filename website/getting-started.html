01In game / Le Mans Ultimate

Enable telemetry recording.

LMU Telemetry reads the telemetry files created by Le Mans Ultimate. Before using the application, make sure telemetry recording is enabled in the game.

Turn on telemetry recording

In the Extra section, activate the option that enables telemetry recording. Once enabled, Le Mans Ultimate will write telemetry files after your sessions.

Important: telemetry files are created whenever you complete a session. Keep this setting enabled so LMU Telemetry can build your history automatically.

02Storage / One source

One shared folder, no duplicate data.

Le Mans Ultimate saves telemetry files in a local folder on your computer. LMU Telemetry reads from that same folder directly, so it does not need to duplicate your files or waste additional disk space.

G:\SteamLibrary\steamapps\common\Le Mans Ultimate\UserData\Telemetry

If Le Mans Ultimate is installed in another Steam library, keep the same relative path inside that library: steamapps\common\Le Mans Ultimate\UserData\Telemetry.

Le Mans Ultimate writes here

Your recorded sessions are saved into this folder by the game.

LMU Telemetry reads here

The app uses the same location to discover, process, and organize your driving data.

Do not move or delete files from this folder unless you no longer want them available in your telemetry history.

03App profile / Folder check

Confirm the folder in LMU Telemetry.

Open the LMU Telemetry application and go to User Profile. The application should normally detect the telemetry folder automatically.

Looks correct

Keep the detected folder selected and continue to synchronization.

Needs attention

Browse to the telemetry folder manually and select the correct location before syncing your data.

04Import / Existing sessions

Save & Sync your telemetry history.

If you already have telemetry files from previous sessions, the first thing to do is press Save & Sync in the User Profile page.

What happens next

LMU Telemetry will scan the selected folder, process your recorded sessions, and turn them into your personal racing history.

Best laps

Session history

Data for future planning

Synchronization processes the telemetry files available in your selected folder.
