Step 01 — In Le Mans Ultimate

Enable telemetry recording once.

LMU Telemetry reads the files produced directly by Le Mans Ultimate. Turn recording on before opening the telemetry application.

  1. Open Le Mans Ultimate.
  2. Open the game Settings.
  3. Scroll to the Extra section.
  4. Enable the telemetry recording option.
  5. Keep the option enabled for future sessions.
Done whenTelemetry recording is enabled in the Extra settings.
What happens: Le Mans Ultimate creates telemetry files for recorded sessions. LMU Telemetry reads those files directly.
Step 02 — Download

Download LMU Telemetry from GitHub.

Open the project’s Releases page and choose a versioned Windows application asset — not GitHub’s automatic source-code archives.

  1. Open the official LMU Telemetry Releases page.
  2. Choose LMUTelemetry-Setup-VERSION.exe to install, or the Portable ZIP to run without installation.
  3. Optionally download SHA256SUMS-VERSION.txt to verify the file.
  4. Do not choose GitHub’s Source code ZIP or tar.gz when you want the Windows application.

Windows displayed a security warning?
Confirm the file came from the official LMU Telemetry Releases page. Compare its filename with the release asset and, when available, verify it against the provided SHA-256 sums. The current packaging configuration does not declare a code-signing identity, so Windows reputation warnings may appear. Do not disable antivirus protection globally or continue with a file from an unverified source.
Step 03 — First launch

Confirm where Le Mans Ultimate saves telemetry.

Start LMU Telemetry, open Career Mode → User Profile, and verify the automatically detected folder. The drive letter or Steam-library prefix is the part most likely to differ.

  1. Start LMU Telemetry.
  2. Open Career Mode, then select User Profile.
  3. Find the Telemetry folder field.
  4. Confirm the drive and final Telemetry folder are correct.
  5. If needed, choose Browse and select the correct folder manually.
Done whenThe selected path ends in Le Mans Ultimate\UserData\Telemetry.
G:\SteamLibrary\steamapps\common\Le Mans Ultimate\UserData\Telemetry

Example only: `G:` is not required. Your game may be in `C:`, `D:`, `E:`, another drive, or another Steam library.

steamapps\common\Le Mans Ultimate\UserData\Telemetry
Correct…\Le Mans Ultimate\UserData\Telemetry
  • The final folder is Telemetry
  • The drive matches your Steam library
Incorrect
  • Le Mans Ultimate root
  • UserData without Telemetry
  • Downloads or the app folder
  • Another game’s telemetry folder
Folder detected correctly

Leave the detected folder selected and continue to Save & Sync.

Folder missing or incorrect

Select Browse, locate the LMU `UserData\Telemetry` directory, and choose that Telemetry folder.

Step 04 — First synchronization

Import the sessions you have already driven.

Once the folder is correct, press Save & Sync. LMU Telemetry scans native session files and builds the cached history used by Career and Plan modes.

  1. Press Save & Sync in User Profile.
  2. Keep the application open while the first scan runs.
  3. Follow the processing phase, message, and percentage shown by the loading overlay.
  4. Wait for the completed state or read the displayed error if the operation fails.
  5. Review Career Overview and validated best laps when processing finishes.
Done whenThe loading overlay closes without an error and Career Overview shows the sessions found in the selected folder.
The first synchronization may take time. A large history can take several minutes and the interface may respond slowly. Do not close the application immediately. Later synchronizations inspect new or changed files rather than rebuilding unchanged sessions.

Troubleshooting

Keep the primary setup flow short. Open only the issue that matches what you are seeing.

Telemetry folder was not detected
  1. Confirm recording is enabled in Le Mans Ultimate.
  2. Confirm the game has created at least one telemetry file.
  3. Check which Steam library contains the game.
  4. In Career Mode → User Profile, browse to `Le Mans Ultimate\UserData\Telemetry`.
  5. Verify the drive letter and final Telemetry folder.
The folder is empty

Sessions completed before telemetry recording was enabled may not have produced the required files. Complete a new recorded session, then check whether Le Mans Ultimate is writing into another Steam library’s `UserData\Telemetry` folder.

Save & Sync appears stuck

Large first-time histories can take several minutes. Follow the visible phase, detail, and percentage; allow the current operation to finish. If there is no change for an unusually long period, restart the application and inspect the logs. For a reproducible problem, open a GitHub issue with the application version, Windows version, approximate file count or size, relevant logs, selected-folder screenshot, and reproduction steps. Review logs and telemetry files for private information before sharing them publicly.

Windows blocks the executable

Return to the official Releases page and verify the filename, release entry, and SHA-256 sums when supplied. The current packaging does not declare a signing identity, so SmartScreen reputation warnings may occur. Do not disable antivirus protection globally and do not continue with a file from an unofficial source.

No previous sessions appear
  • Sessions may predate telemetry enablement.
  • Files may be in another Steam-library folder.
  • Invalid or unsupported files may be skipped.
  • The files may not have been processed through Save & Sync yet.
I installed Le Mans Ultimate on another drive

Only the drive and Steam-library prefix normally change. These are examples, not guaranteed paths:

  • C:\Program Files (x86)\Steam\steamapps\common\Le Mans Ultimate\UserData\Telemetry
  • D:\SteamLibrary\steamapps\common\Le Mans Ultimate\UserData\Telemetry
  • G:\SteamLibrary\steamapps\common\Le Mans Ultimate\UserData\Telemetry
