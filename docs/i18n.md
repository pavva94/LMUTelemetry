# Internationalization

The frontend has a centralized i18n layer in `frontend/src/i18n`.

## Files

- `resources.ts` contains English (`en`) and Italian (`it`) resource trees.
- `core.ts` contains language detection, local persistence, interpolation, plural selection, fallback lookup, and completeness validation.
- `I18nProvider.tsx` exposes `useI18n()` and `useT()` to React components.
- `core.test.ts` verifies default language selection, persistence reads, fallback behavior, pluralization, interpolation, and key completeness.

## Adding A Translation Key

Add the same semantic key to both language trees. Use stable keys such as `settings.refreshRate`, not visible English text. Prefer a full sentence with interpolation over building translated copy with string concatenation.

Example:

```ts
common: {
  lastUpdated: "Last updated {{time}} ago"
}
```

Usage:

```tsx
const t = useT();
return <span>{t("common.lastUpdated", { time: "4 min" })}</span>;
```

## Plurals

Plural entries use `_one` and `_other` suffixes and are selected when `count` is provided.

```ts
common: {
  laps_one: "{{count}} lap",
  laps_other: "{{count}} laps"
}
```

Usage:

```tsx
t("common.laps", { count: lapCount })
```

## Adding A Language

1. Add the language code and native name to `languages` in `resources.ts`.
2. Add a full resource tree with every key from English.
3. Update `localeFor()` in `frontend/src/i18n/format.ts` if the language needs a specific BCP 47 locale.
4. Run `npm run i18n:validate` from `frontend`.

## Language Selection

The Settings page includes a language selector. The selected language is stored in `localStorage` under `lmu-language`; if no preference exists, the app detects the browser locale and falls back to English for unsupported languages.

## Formatting

Use the `formatNumber`, `formatDateTime`, and `formatRelativeTime` helpers from `useI18n()` for user-facing numeric/date/time output. Do not convert telemetry units during localization; keep units as data display labels and preserve motorsport abbreviations such as RPM, ABS, TC, GT3, and LMP2.

## Validation

Run:

```bash
npm run i18n:validate
```

This checks resource presence and runs the i18n test suite, including English/Italian key completeness.
